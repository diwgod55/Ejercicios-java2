# Ejercicios en Java (Ejercicios-java2)

Repositorio dedicado a la práctica, resolución y recopilación de ejercicios de programación en Java. Este espacio está enfocado en consolidar los fundamentos del lenguaje, la lógica de programación y la resolución de problemas algorítmicos.

---

## Tecnologías y Requisitos

Para compilar y ejecutar los ejercicios de este repositorio, se requiere:

* Java Development Kit (JDK): Versión 8 o superior (recomendado JDK 17 o superior).
* Entorno de desarrollo integrado (IDE) o editor de código (IntelliJ IDEA, Eclipse, NetBeans, Visual Studio Code, etc.).

---

## Instrucciones de Instalación y Ejecución

1. Clonar el repositorio:
   ```bash
   git clone [https://github.com/diwgod55/Ejercicios-java2.git](https://github.com/diwgod55/Ejercicios-java2.git)

   Abrir la carpeta del proyecto en el IDE o editor de preferencia.

Compilar y ejecutar la clase principal del ejercicio deseado.

Estructura del Repositorio
El repositorio incluye ejercicios orientados a la práctica de:

Estructuras de control condicionales y de repetición.

Conceptos fundamentales de Programación Orientada a Objetos (POO).

Manejo de arreglos y colecciones de datos.

Algoritmos básicos de ordenamiento y búsqueda.
